About this data: By default this shows the schools with men's varsity lacrosse (D1/D2/D3/NAIA) and a physical therapy pathway — either a guaranteed freshman-entry 3+3 DPT program, or an accredited DPT program on campus. Division, location, and public/private status are researched and complete for those schools. SAT, GPA, and tuition figures are pulled from official or aggregator sources where available — figures shown with a dashed underline are unverified or estimated; hover for details, and always confirm with the school directly before treating any number as final.

Turn on "Show all lacrosse schools" in the filter panel to also see every other men's lacrosse program nationally — no confirmed PT program found in this project's research, but a general pre-med/pre-health track could still work at any of them. Those extra schools only have division, location, and public/private status researched — no SAT/GPA/tuition data yet, shown as "—".

Use + Add school or the edit button on any card to correct or extend the data — your changes save in this browser automatically.
